# Employee Management System

A web-based Employee Management System developed using Java Servlets, JSP, JDBC, MySQL, and Maven.

## Features

- Add new employee
- View all employees
- Update employee details
- Delete employee
- MySQL database integration
- JSP-based user interface
- CRUD operations using JDBC

## Technologies Used

- Java 17
- Java Servlets
- JSP
- JSTL
- JDBC
- MySQL
- Maven
- Apache Tomcat 9
- HTML
- CSS
